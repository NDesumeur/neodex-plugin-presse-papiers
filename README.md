# Presse-papiers

L'historique de ce que tu copies, dans NeoDex. Chaque texte copié (n'importe où dans Windows) est gardé :
cherche dedans, épingle ce que tu réutilises souvent, clique sur un élément pour le recopier.
**Ctrl+Alt+H** ouvre l'historique de n'importe où.

- Les 200 derniers éléments sont gardés ; les épinglés ne partent jamais tout seuls.
- Ce qu'un gestionnaire de mots de passe marque « à ne pas garder » n'est jamais enregistré.
- Le bouton **Pause** arrête l'enregistrement le temps qu'il faut.
- Tout reste sur ton ordinateur, dans le dossier du plugin.

## Installer

Dans NeoDex : **NeoStore → À découvrir → Presse-papiers → Installer**.

## Développer un plugin

Le format et le guide sont dans le [SDK NeoDex](https://github.com/NDesumeur/neodex-sdk).
